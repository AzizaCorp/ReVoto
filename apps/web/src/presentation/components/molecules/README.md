# Moléculas

Grupos pequeños de átomos que cumplen una sola tarea: cifra con su contexto, chip de territorio, campo con etiqueta, aviso.

- **Puede importar:** átomos y tipos de `@/domain`.
- **No puede importar:** organismos, plantillas ni `application`, `pages` o `infrastructure`.
- **Regla clave:** `CifraConContexto` es la única forma de mostrar una cifra en una pantalla (RN-10).

Inventario planeado: ver `../README.md` › Moléculas.
