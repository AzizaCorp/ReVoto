# Plantillas

Esqueletos de pantalla sin contenido real. Definen zonas y comportamiento de layout; las páginas las llenan.

- **Puede importar:** organismos, moléculas y átomos.
- **No puede importar:** `application`, `infrastructure` ni páginas.
- **Recibe:** contenido por `children` o por props con nombre (`superior`, `contenido`, `inferior`).

| Plantilla | Zonas | Manual |
| --- | --- | --- |
| `PantallaNarrativa` | 56 px · 632 px sin scroll · 72 px | §7.1 |
| `PlantillaHoja` | ~70 % del alto, fondo atenuado, foco atrapado | §7.2 |
| `PantallaUtilitaria` | «‹ Volver» + título, scroll, acción fija | §7.3 |
| `PantallaLigera` | Solo texto y tablas | RF-18 |
