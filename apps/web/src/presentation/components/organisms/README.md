# Organismos

Secciones completas y reutilizables de la interfaz: barra superior, barra inferior, hoja inferior, gráficas, selector de territorio.

- **Puede importar:** átomos, moléculas y tipos de `@/domain`.
- **No puede importar:** plantillas ni `application`, `pages` o `infrastructure`.
- **Gráficas:** toda visualización incluye texto alternativo completo (cifra, territorio y periodo) y una `TablaAlternativa` (RF-17, RIU-04). Intermedias y presidenciales se distinguen por relleno (RN-03).
