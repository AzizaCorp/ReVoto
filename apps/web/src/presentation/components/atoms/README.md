# Átomos

Elementos mínimos de la interfaz que no se pueden dividir sin perder su función: botón, texto, cifra, interruptor, selector.

- **Puede importar:** React, tipos y funciones puras de `@/domain`.
- **No puede importar:** moléculas, organismos, plantillas ni `application`, `pages` o `infrastructure`.
- **Recibe:** props simples (texto, variante, estado). No conoce territorios, elecciones ni pantallas.
- **Accesibilidad:** cada átomo interactivo expone su nombre accesible, foco visible y objetivo táctil ≥ 44 px.
